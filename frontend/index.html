Multi-Tenant SaaS Architecture

Tizim Arxitekturasi, Ma'lumotlar Bazasi Sxemasi va GitHub Joylashtirish

FastAPI + PostgreSQL RLS + React/Tailwind
1. Superadmin & Security Layer

Superadmin hisobi Argon2id xeshlash + TOTP 2FA + IP Whitelist bilan himoyalangan. Har bir do'kon qo'shilganda secrets.token_urlsafe orqali bir martalik parol (OTP) yaratiladi va must_change_password = True belgilanadi.

2. Subscription & Lock Middleware

FastAPI TenantGuardMiddleware har bir API so'rovda do'konning status == 'ACTIVE' va subscription_expires_at >= today ekanligini tekshiradi. Bloklangan yoki muddati o'tgan do'konlar darhol to'xtatiladi.

3. Tenant Isolation (PostgreSQL)

Barcha products, customers, sales, inventory_logs jadvallarida store_id (UUID) indeksi va PostgreSQL Row-Level Security (RLS) ishlaydi — bir do'kon boshqa do'kon ma'lumotlarini hech qachon ko'ra olmaydi.
